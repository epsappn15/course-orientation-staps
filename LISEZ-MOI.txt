COURSE D'ORIENTATION STAPS / SUAPS — V34.1 CORRIGÉE

Cette archive contient le projet complet :
- serveur Node.js et configuration Render ;
- interface participant et gestionnaire ;
- logos STAPS et SUAPS ;
- manifest et service worker ;
- fonctionnalités V34, dont le pointage QR.

CORRECTION V34.1
Le bouton principal « SCANNEZ LA BALISE DÉPART » ouvre maintenant directement
la caméra en mode « Pointage QR uniquement ». En mode GPS, le bouton conserve
son démarrage normal. Un message explicite est affiché si la caméra est bloquée,
indisponible ou si l'accès HTTPS manque.

DÉPLOIEMENT SUR RENDER
1. Décompresser cette archive.
2. Déployer le contenu du dossier sur le dépôt GitHub connecté à Render
   (en conservant les dossiers et sous-dossiers).
3. Conserver les variables d'environnement déjà configurées sur Render :
   TURSO_DATABASE_URL, TURSO_AUTH_TOKEN, ADMIN_USER, ADMIN_PASSWORD,
   SESSION_SECRET et PUBLIC_URL.
4. Lancer un nouveau déploiement.
5. Sur le téléphone, fermer l'ancien onglet de l'application puis rouvrir
   l'adresse Render en HTTPS. Si nécessaire, actualiser la page.

Le dossier public doit rester à la racine du projet, au même niveau que server.js.
Ne pas publier les identifiants ni les secrets dans le dépôt.

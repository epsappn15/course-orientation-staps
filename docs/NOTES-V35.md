# V35 — Intégration pédagogique MSA-APN

La V35 conserve le socle V34.1 et ajoute un module pédagogique facultatif, activable séance par séance par le gestionnaire.

## Référence utilisée
Document MSA-APN transmis dans la conversation : « Modèle de Sécurité Adaptative des Activités de Pleine Nature », Nicolas Hayer, Université de Poitiers, 2026. La reproduction de référence est conservée dans ce dossier.

## Contenu repris du document
- 4 principes : A Anticipation ; B Régulation ; C Prise de décision ; D Action responsable.
- 8 dimensions : Information ; Préparation ; Équipement ; Compétences ; Sécurité ; Adaptation ; Environnement ; Attitude.
- Boucle décisionnelle en 7 étapes : Prévoir ; Vérifier ; Évaluer ; Agir ; Observer ; Adapter ; Décider.
- 3 zones de décision : zone maîtrisée → poursuivre ; zone d’adaptation → modifier le projet ; zone de rupture → renoncer / se mettre en sécurité.

## Fonctionnalités ajoutées
- Réglage gestionnaire par séance (désactivé par défaut).
- Parcours participant : préparation, évaluation de situation/zone, décision et retour d’expérience.
- Enregistrement distinct des résultats de chronométrage.
- Consultation des bilans depuis l’espace gestionnaire.

## Limites et précautions
Le module est un support pédagogique et déclaratif. Il ne constitue ni un dispositif de secours, ni une certification des compétences, ni une évaluation automatique de la maîtrise du risque. Les consignes opérationnelles de sécurité et d’alerte restent définies par l’encadrement.
